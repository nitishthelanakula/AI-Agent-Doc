# Source Freshness Procedure

## Objective

Treasury reports rely on timely and trusted source data. This procedure defines the minimum expectations for source freshness before data can be used in liquidity reporting.

## Minimum standards

- Data must be extracted from the source system on the current reporting day.
- Any data older than the established reporting cutoff should be treated as stale.
- Manual overrides must be clearly labeled and approved by the responsible treasury reviewer.
- Source exceptions must be documented with the reason, owner, and expected resolution time.

## Review trigger

A report is considered out of compliance if source data is delayed, incomplete, or inconsistent with the prior reporting period without documented explanation.

## Escalation

When source freshness is at risk, the reporting owner should notify the treasury lead, identify the impacted metrics, and document the remediation plan before final publication.
